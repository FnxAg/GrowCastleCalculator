# Grow Castle Calculator / 成长城堡计算器

A simple Android calculator with some tools for the mobile game "Grow Castle".

游戏《Grow Castle》（成长城堡）的辅助计算器，并提供一些实用工具，适用于安卓系统。

## Features / 功能

- Ratio Calculator / 比例计算
- GP Calculator / 指数计算
- Gold Calculator / 金币计算
- Time Till Reset / 重置倒计时
- Infinite Colony Calculator / 通天塔比例与收入计算
- Player and Guild Info Query / 玩家和公会信息查询
- WPH Query / WPH 查询
- Custom Query API / 可自定义API
